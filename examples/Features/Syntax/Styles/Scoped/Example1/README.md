# Scoped

Identical selectors stay isolated across two components. The parent paragraph is blue and the child paragraph is red.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Styles/Scoped/Example1/Viu.Syntax.Styles.Scoped.Example1.csproj
```

Change the value or click the control to observe this feature alone.
