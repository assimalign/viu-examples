# Slotted

A scoped receiver styles a projected native slot root with :slotted().

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Styles/Slotted/Example1/Viu.Syntax.Styles.Slotted.Example1.csproj
```

Change the value or click the control to observe this feature alone.
