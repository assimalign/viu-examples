# CssModules

A generated module accessor supplies the collision-free class name.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Styles/CssModules/Example1/Viu.Syntax.Styles.CssModules.Example1.csproj
```

Change the value or click the control to observe this feature alone.
