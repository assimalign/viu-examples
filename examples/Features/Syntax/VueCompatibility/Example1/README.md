# VueCompatibility

The .vue compatibility container accepts explicitly C# script setup and scoped styles.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/VueCompatibility/Example1/Viu.Syntax.VueCompatibility.Example1.csproj
```

Change the value or click the control to observe this feature alone.
