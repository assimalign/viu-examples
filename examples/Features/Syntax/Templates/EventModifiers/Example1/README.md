# EventModifiers

The once modifier removes the listener after its first invocation.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Templates/EventModifiers/Example1/Viu.Syntax.Templates.EventModifiers.Example1.csproj
```

Change the value or click the control to observe this feature alone.
