# RawHtml

v-html inserts a known HTML string; ordinary interpolation displays the same string as text.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Templates/RawHtml/Example1/Viu.Syntax.Templates.RawHtml.Example1.csproj
```

Change the value or click the control to observe this feature alone.
