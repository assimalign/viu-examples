# NumericModel

A numeric input converts its native value to a typed numeric model.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Syntax/Templates/NumericModel/Example1/Viu.Syntax.Templates.NumericModel.Example1.csproj
```

Change the value or click the control to observe this feature alone.
