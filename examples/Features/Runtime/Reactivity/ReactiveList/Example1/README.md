# ReactiveList

Adding to a reactive collection updates a keyed list.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Reactivity/ReactiveList/Example1/Viu.Runtime.Reactivity.ReactiveList.Example1.csproj
```

Change the value or click the control to observe this feature alone.
