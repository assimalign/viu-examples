# Watch

A component-owned watch receives the current and previous values and stops on unmount.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Reactivity/Watch/Example1/Viu.Runtime.Reactivity.Watch.Example1.csproj
```

Change the value or click the control to observe this feature alone.
