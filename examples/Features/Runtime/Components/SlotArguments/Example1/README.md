# SlotArguments

A child supplies arguments to caller-owned slot content.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Components/SlotArguments/Example1/Viu.Runtime.Components.SlotArguments.Example1.csproj
```

Change the value or click the control to observe this feature alone.
