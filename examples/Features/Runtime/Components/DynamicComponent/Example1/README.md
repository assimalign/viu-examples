# DynamicComponent

A typed registration selects a component dynamically without reflection activation.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Components/DynamicComponent/Example1/Viu.Runtime.Components.DynamicComponent.Example1.csproj
```

Change the value or click the control to observe this feature alone.
