# NamedSlots

Named and default slots fill three independent child regions.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Components/NamedSlots/Example1/Viu.Runtime.Components.NamedSlots.Example1.csproj
```

Change the value or click the control to observe this feature alone.
