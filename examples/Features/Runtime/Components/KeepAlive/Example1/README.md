# KeepAlive

KeepAlive retains one counter per key while the active key changes.

Read App.viu; the browser bootstrap is shared under Shared/. Run from the feature root:

```powershell
dotnet run --project Runtime/Components/KeepAlive/Example1/Viu.Runtime.Components.KeepAlive.Example1.csproj
```

Change the value or click the control to observe this feature alone.
